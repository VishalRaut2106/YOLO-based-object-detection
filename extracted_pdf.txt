PROBLEM STATEMENT : 
In the modern digital era, a vast amount of image data is generated every day through social media, 
surveillance systems, medical imaging, and various other applications. Manually analyzing and 
classifying these images is time-consuming, inefficient, and prone to human error. Therefore, there 
is a growing need for automated systems that can accurately detect and classify objects within 
images. 
This project addresses the problem of developing an efficient and reliable image classification 
system using a Convolutional Neural Network (CNN). The system is designed to automatically 
identify and categorize objects present in images without human intervention. 
The model is trained using the CIFAR-10 dataset, which consists of low-resolution images (32×32 
pixels) belonging to multiple classes such as vehicles, animals, and everyday objects. Due to the 
small image size and limited feature details, achieving high classification accuracy becomes a 
challenging task. 
The objective of this project is to design and implement a CNN-based model that can effectively 
learn image features and classify them into appropriate categories with acceptable accuracy. The 
system aims to provide a simple yet effective solution for object detection and classification, 
which can be further extended to real-world applications. 
INTRODUCTION: 
 
With the rapid growth of digital technology, a large number of images are generated and shared every day. 
Analyzing and understanding these images manually is time-consuming and inefficient. Therefore, 
automated systems are required to identify and classify objects present in images. 
 
Artificial Intelligence and Machine Learning have made significant advancements in the field of image 
processing. Among these, Convolutional Neural Networks (CNNs) are widely used for image recognition 
and classification tasks. CNNs are capable of automatically extracting important features such as edges, 
shapes, and patterns from images, making them highly effective for visual data analysis. 
 
This project focuses on developing a CNN-based model to detect and classify objects in images. The 
system is trained using the CIFAR-10 dataset, which consists of various categories such as animals, 
vehicles, and everyday objects. Even though the images in the dataset are of low resolution, CNN models 
can still learn meaningful features and perform accurate classification. 
 
The main aim of this project is to build a simple and efficient model that can automatically identify the 
object present in an image and classify it into the correct category. This approach demonstrates the 
practical application of CNNs in solving real-world image recognition problems.

import tensorflow as tf 
import numpy as np 
import cv2 
import sys 
import os 
 
MODEL_PATH = "car_detector.h5" 
IMG_SIZE = 128 
 
def load_model(model_path=MODEL_PATH): 
"""Load model lazily — call once and reuse.""" 
if not os.path.exists(model_path): 
raise FileNotFoundError( 
f"Model not found at '{model_path}'. Run train.py first." 
) 
return tf.keras.models.load_model(model_path) 
 
def predict_image(img_path: str, model=None) -> dict: 
""" 
Predict whether an image contains a car. 
 
Returns a dict: 
{ 
"label": 
"Car Detected" | "No Car Detected", 
"confidence": float (0-1), 
"raw_score": float, 
} 
""" 
if not os.path.exists(img_path): 
raise FileNotFoundError(f"Image not found: {img_path}") 
 
img = cv2.imread(img_path) 
if img is None: 
raise ValueError(f"Could not read image: {img_path}") 
 
img_resized = cv2.resize(img, (IMG_SIZE, IMG_SIZE)) / 255.0 
img_input = np.expand_dims(img_resized, axis=0) 
 
if model is None: 
model = load_model() 
 
raw_score = float(model.predict(img_input, verbose=0)[0][0]) 
is_car 
= raw_score > 0.5 
confidence = raw_score if is_car else 1 - raw_score 
 
return { 
"label": 
"Car Detected ._ fi  " if is_car else "No Car Detected +", 
"confidence": round(confidence * 100, 2), 
"raw_score": round(raw_score, 4), 
}
